# 🏦 Bankist Application

A modern and interactive **banking web application** built using **JavaScript, HTML, and CSS**, focusing on real-world financial operations and dynamic UI updates.

## 🚀 Live Demo

🔗 Play here: https://iammissmiller.github.io/Bankist-Application/

---

## 📌 About the Project

The **Bankist App** simulates core banking functionalities such as money transfers, loan requests, and account management.

This project was built while learning JavaScript and focuses on applying advanced concepts to create a real-world-like application.

It significantly improved my understanding of:

* Complex DOM manipulation
* State management
* Array methods and data transformations
* User interaction handling

## 🎮 Features

* 🔐 User authentication (login system)
* 💸 Transfer money between accounts
* 🏦 Request loans
* ❌ Close account
* 📊 Transaction history display
* ⏱️ Auto logout timer for security
* 🔄 Sort transactions
* 🎨 Clean and responsive UI
